# 问题2、3 建模数据

对应题目：
- **问题2**：以品类为单位做补货计划（未来一周 2023-07-01~07 的日补货总量与定价策略）
- **问题3**：单品级补货（基于 2023-06-24~30 可售品种，给出 7-1 单品补货量与定价）

数据来自附件1~4，全部为 utf-8-sig CSV。

| 文件 | 说明 |
|---|---|
| `商品信息表.csv` | 单品字典 |
| `损耗率表.csv` | 每单品：单品损耗率 + 品类平均损耗率（附件4 两 sheet 合并） |
| `单品_批发价原始.csv` | 附件3 原始批发价 |
| `单品_批发价_前向填充面板.csv` | 每单品逐日“最近一次批发价”成本面板 |
| `单品_日销售建模总表.csv` | **单品级主表**：日销量+均价+当日成本+损耗+加成率+有效成本（问题3 基础） |
| `品类_日销售汇总.csv` | 品类×日（有销日）：零售均价/加权成本/加成率/品类均损（问题2 基础） |
| `品类_日销售_完整面板.csv` | 1095 天×6 类完整面板（停业 NaN / 无销 0），补货时序建模直接可用 |
| `2023-06-24至30_单品日销售明细.csv` | 问题3 窗口期 7 天单品×日明细（283 行） |
| `2023-06-24至30_可售品种清单.csv` | 窗口期可售 49 品种及该周销量/成本/损耗（问题3 候选池） |

要点：
- `当日成本价` = 该日或此前最近一次批发价（向前填充）。
- `成本价异常标记=1` 表示成本 <0.5 元/千克（疑录入错误），算加成率前建议剔除。
- `有效单位成本 = 当日成本价 ÷ (1 − 单品损耗率)`，补货量需按损耗放大（订购 q/(1−损耗) 卖得 q）。

详细口径见上级目录《数据处理与清洗说明.md》。
