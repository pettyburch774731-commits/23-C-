# 问题一审计输出

本目录保存本次审计的轻量、可直接复核输出：附件审计摘要、异常记录样例、每日正常销售/退货/净销量对账、日期记录覆盖、单品活跃期和现有日表控制核验。

完整重算的单品日表、品类日表、完整品类面板、总体统计表和 30,135 个单品对 overlap 表没有再次提交，以免与 `问题1_建模数据/` 中已有的大型派生表重复存储。运行以下命令即可在本目录再生全部输出：

```powershell
python src/problem1/audit_problem1_data.py --source-dir origin_data
```

脚本只读取 `origin_data/附件1.xlsx` 与 `origin_data/附件2.xlsx`，不会修改原始附件或既有建模表。若从该审计分支的仓库根目录运行，默认会自动和 `问题1_建模数据/` 中的两个日汇总表逐字段核对。
