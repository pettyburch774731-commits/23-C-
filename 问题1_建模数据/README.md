# 问题1 建模数据

对应题目：**问题1——分析蔬菜各品类及单品销售量的分布规律及相互关系**

数据均来自「附件1 商品信息 + 附件2 销售流水（仅销售、剔除退货）」，全部为 utf-8-sig CSV。

| 文件 | 说明 |
|---|---|
| `商品信息表.csv` | 251 个单品及所属分类（附件1） |
| `单品_日销售汇总.csv` | 日期×单品 销量/销售额/笔数/打折/加权平均售价 |
| `品类_日销售汇总.csv` | 日期×品类 汇总（含在售单品数） |
| `单品_总体统计.csv` | 3 年单品级统计（销售天数/总量/日均/变异系数…），供分布规律与排名 |
| `品类_总体统计.csv` | 3 年品类级统计 |
| `品类_日销售宽表.csv` | 行=全日历(1095天)、列=6 品类 的日销量矩阵（停业日=NaN），品类相关/聚类直接用 |
| `营业日历.csv` | 每天是否有销售/批发价记录 |

详细口径见上级目录《数据处理与清洗说明.md》。
